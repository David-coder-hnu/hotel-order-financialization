\section{场景引入：为什么需要"时权"？}
% ============================================================

\subsection{张三的酒店}

假设张三在成都开了一家酒店：60间房，均价\yen 1,930/晚，入住率62\%。年收入约\yen 2,760万。

张三的烦恼：
\begin{enumerate}[nosep]
    \item \textbf{现金流不稳定：}淡季没钱，旺季忙不过来。收入分散在12个月。
    \item \textbf{OTA 抽成：}携程、美团抽15-25\%佣金。
    \item \textbf{贷款难：}没有房产抵押，银行不贷。即使贷到，利率10-15\%。
    \item \textbf{想扩张：}需要资金开第二家店，但钱都压在"未来收入"里。
\end{enumerate}

\begin{analogy}
张三的酒店像一块"未来收入的冰块"——有价值，但在太阳下（不确定性）不断融化。时权系统就是把冰块提前卖了换现金。
\end{analogy}

\subsection{时权的解决方案}

\textbf{平台作为做市商（两层市场结构）：}

第一步：张三把未来房间以\textbf{批发价}卖给平台（¥1,174/间夜），立刻拿到现金。

第二步：平台以\textbf{零售价}卖给用户和投资者（¥1,268/间夜，平台加价8\%赚价差）。

第三步：用户买了时权后，\textbf{可以在任何时间}在二级市场卖出。卖出的钱直接当"住宿券"用——订任何酒店都能抵扣。优惠是市场给的（供需决定），不是酒店给的（酒店不收一分钱折扣）。

\textbf{两种退出机制（这是理解系统的关键）：}
\begin{itemize}[nosep]
    \item \textbf{随时退出（主力）：}在二级市场卖出时权，卖得的钱直接当住宿券用。折扣由市场供需决定——不是固定数字，需求旺时折扣更大。
    \item \textbf{到期退出（保底）：}持有到到期日，三选一——现金/7折入住/转卖。7折是固定保底价，保证时权不会变得一文不值。
\end{itemize}

\textbf{四方都赢：}
\begin{itemize}[nosep]
    \item 张三：提前锁定收入，每可用间夜比OTA多赚55\%
    \item 用户：市场驱动的折扣（约4.4\%），优惠不由酒店承担
    \item 平台：赚批发-零售价差+交易手续费
    \item 投资者：73\%名义回报，承担违约和流动性风险
\end{itemize}

\section{知识准备：五个基本概念}
% ============================================================

\subsection{什么是"资产"？}
\begin{concept}
\textbf{资产} = 能带来未来经济利益的东西。"明年6月15日住张三家酒店的权利"也是资产——它有经济价值，只是还没变成可交易的形式。
\end{concept}

\subsection{什么是"证券化(ABS)"？}
\begin{concept}
\textbf{资产证券化} = 把一堆未来现金流的资产打包，切成不同风险等级的"片"，卖给不同的人。像把一头猪分解成里脊肉(最贵)、五花肉(中等)、猪蹄(便宜)——不同部位不同价。
\end{concept}

\subsection{什么是"信用风险"？}
\begin{concept}
\textbf{信用风险} = 对方不履行承诺的概率。酒店可能关门 → 时权到期无法入住 → 违约。我们需要一个模型来估算这个概率。
\end{concept}

\subsection{什么是"蒙特卡洛模拟"？}
\begin{concept}
\textbf{蒙特卡洛} = 计算机生成10,000种"可能的未来"，看每种情况下结果是什么。不是预测一个未来，而是看所有可能的未来中，最坏的情况有多坏。
\end{concept}

\subsection{什么是"Copula"？}
\begin{concept}
\textbf{Copula} = 描述"多个事件同时发生"的数学工具。成都地震 → 80家酒店同时违约。Copula建模这种"一起出事"的概率。\textbf{Gaussian Copula}假设极端事件不相关（但现实是相关的——2008年金融危机的教训）。\textbf{t-Copula}更好地捕捉这种尾部依赖。
\end{concept}

\subsection{Section 2: FSR Definition（FSR定义）}

\textbf{本章核心公式：}
\begin{equation}
    S = (c, T, \ell, \sigma)
\end{equation}

\textbf{人话翻译：} 一个FSR就是四样东西的组合——多少量(c)、什么时候(T)、在哪里($\ell$)、什么类型($\sigma$)。

\textbf{FSR vs RWA 的核心区别：}
\begin{itemize}[nosep]
    \item RWA：国债、房产证、发票 → \textbf{已有资产数字化}
    \item FSR：未来酒店房间、未来机票座位 → \textbf{创造新资产}
    \item "RWA是搬运工，FSR是创造者"
\end{itemize}

\textbf{FSR存在的三个条件（Section 2.2）：}
\begin{enumerate}[nosep]
    \item \textbf{可验证的质量信号：}酒店星级、历史入住率——投资者不能瞎买
    \item \textbf{超发机制：}$\omega = (1/\rho) \times \phi$。酒店卖1.29间夜/每物理间夜。补偿取消和No-show。
    \item \textbf{有限责任+追索：}酒店违约了，投资者还有替代酒店和二级市场可退出
\end{enumerate}

\begin{warning}
\textbf{超发公式在2026年5月修正。} 原论文写的是 $\omega = 1/(\rho\cdot\phi)$（分母），实际代码中是 $\omega = (1/\rho) \times \phi$（分子）。前者暗示$\phi$在分母上减少超发（保守），后者正确反映了$\phi<1$产生安全缓冲。
\end{warning}

% -------- SECTION 3: PRICING --------
\subsection{Section 3: Pricing Framework（定价框架）}

\textbf{本文采用两层定价结构——这是2026年5月新增的关键设计：}

\subsubsection{公式1a：批发发行价（酒店→平台）}
\begin{equation}
    P_{\text{issue}} = P_{\text{base}} \cdot \delta(T) \cdot (1 - d_{\text{issue}})
\end{equation}
\textbf{人话：} 基础价 × 远期折扣 × (1-发行折扣)。校准值：¥1,613 × 0.787 × 0.90 ≈ \textbf{¥1,174/间夜}。

\subsubsection{公式1b：零售价（平台→用户/投资者）}
\begin{equation}
    P_{\text{retail}} = P_{\text{issue}} \cdot (1 + m)
\end{equation}
\textbf{人话：} 平台在批发价上加价$m=8\%$后卖给用户。校准值：¥1,174 × 1.08 ≈ \textbf{¥1,268/间夜}。

\textbf{为什么要两层定价？} 平台作为做市商：从酒店批量购买时权(批发价)，分销给用户和投资者(零售价)，赚取价差。用户也可以直接在二级市场买卖——二级市场价$P_{\text{secondary}}$由供需决定，通常接近零售价。

\textbf{参数说明：}
\begin{itemize}[nosep]
    \item $P_{\text{base}}$: 酒店历史中位价（数据驱动）
    \item $\delta(T)=e^{-rT}$: 时间价值。$r=8\%$(WACC估计), $T=3$年
    \item $d_{\text{issue}}=10\%$: 批发折扣(JUDGMENT, 可调)
    \item $m=8\%$: 平台零售加价(JUDGMENT, 可调)
\end{itemize}

\subsubsection{公式2：二级市场价}
\begin{equation}
    P_t = P_{\text{spot}} + (P_{\text{issue}} - P_{\text{spot}}) \cdot e^{-\lambda(T-t)} + \eta_t
\end{equation}

\textbf{人话：} 时权价格像倒计时——越接近使用日期，越接近当天酒店真实价格。$\lambda$控制收敛速度，$\eta_t$是供需噪音。

\begin{figure}[H]
\centering
\includegraphics[width=0.7\textwidth]{figures/fig1_price_convergence.png}
\caption{Fig 1: 价格收敛路径。阴影带=±5\%。随着到期日逼近，时权价格从批发发行价(\yen 1,174)收敛到即期酒店价(\yen 2,029)。}
\end{figure}

\subsubsection{公式3：兑付价值}
\begin{equation}
    V_{\text{settle}} = \max\{\, V_{\text{cash}},\; \alpha \cdot P_{\text{spot}},\; P_{\text{secondary}} \,\}
\end{equation}

\textbf{人话：} 到期时自动选最划算的那个——拿现金、固定折扣住房($\alpha$)、还是二手卖掉。$\max$操作保证时权有保底价值。\textbf{注意：这是到期保底机制，不是主力退出方式。}主力方式是随时在二级市场卖出（下一节详解）。

\textbf{参数：}$\alpha=0.70$（到期固定折扣，仅用于保底）。实际用户获得的折扣通常由市场决定而非$\alpha$。

% -------- SECTION 4: CREDIT RISK --------
\subsection{Section 4: Credit Risk and Structuring（信用风险与分层）}

\subsubsection{公式4：Merton违约距离}
\begin{equation}
    DD_i = \frac{\ln(V_i / D_i) + (\mu - \sigma_i^2/2)T}{\sigma_i \sqrt{T}}
\end{equation}

\textbf{人话：} 酒店当前的"财务健康度"离"经营困难"有多远。分子是"资产价值 vs 违约边界的距离"，分母是"不确定性(波动率)"。波动越大的酒店，DD越小 → 违约风险越高。

\textbf{参数详解：}
\begin{itemize}[nosep]
    \item $V_i$ = 酒店均价（用价格替代资产价值——Merton模型是为上市公司设计的，用在酒店上是近似）
    \item $D_i = 0.55 \times V_i$（违约边界=均价的55\%。JUDGMENT——如果酒店收入降到正常的55\%，认为它陷入困境）
    \item $\sigma_i$ = GARCH(1,1)估计的年化波动率，按酒店等级调整（经济×1.2，豪华×0.65）
    \item $\mu=0.03$（漂移率，JUDGMENT）
\end{itemize}

\subsubsection{公式5：违约概率}
\begin{equation}
    PD_i = \min\left( \Phi(-DD_i) \times 2.5,\; 0.50 \right)
\end{equation}

\textbf{人话：} DD → 正态分布查表 → 乘以2.5校准因子(因为Merton倾向低估PD) → 封顶50\%。

\begin{warning}
\textbf{这个50\%上限极其重要。} 2026年5月的审计发现：66家酒店中65家撞在50\%上限上（加权平均PD=49.4\%）。去掉上限后PD=98.2\%——Merton模型认为几乎所有酒店都该违约。换成KMV模型则只有9.8\%。真实值在这之间。

\textbf{所有护栏参数现已在credit\_model.py中可配置：}pd\_cap、pd\_floor、vol\_floor、dd\_floor、default\_barrier\_ratio、pd\_calibration、drift\_rate。
\end{warning}

\subsubsection{公式6：Gaussian Copula}
\begin{equation}
    u_i = \sqrt{\rho_{\text{sys}}} \cdot Z_{\text{sys}} + \sqrt{1 - \rho_{\text{sys}}} \cdot \varepsilon_i
\end{equation}

\textbf{人话：} 每家酒店的违约由两部分组成——70\%来自"大家一起倒霉"的系统因子($Z_{sys}$)，30\%来自"只有我倒霉"的异质因子($\varepsilon_i$)。这是单因子模型——最简化的相关性结构。

\textbf{Table 2 (资产池特征)：} 80家酒店，总面值\yen 1,544万(分)，均价\yen 193,036(分)=\yen 1,930/晚。加权PD=33.9\%，加权LGD=70.8\%，加权EL=25.1\%。地理HHI=0.220(18区县)，Top-5集中度=13.9\%。

\textbf{Table 3 (分层结构)：} Senior 68\%(AAA, 4.5\%) / Mezz 20\%(BBB, 6.5\%) / Junior 8\%(B, 9.5\%) / Equity 4\%(NR, 0\%)。信用支持：Senior有32\%的下层吸收损失。OC测试<100\%触发加速清偿。累计违约>15\%触发违约事件。

% -------- SECTION 5: MECHANISM DESIGN --------
\subsection{Section 5: Mechanism Design（机制设计）}

\textbf{三个形式化证明：}

\subsubsection{证明1：策略防护(Strategy-Proofness)}
\textbf{命题：}诚实报告自己的偏好类型是弱占优策略。

\textbf{证明思路：} 因为$V_{\text{settle}} = \max\{C, \alpha P_{\text{spot}}, P_{\text{secondary}}\}$，无论你说什么，系统都给你最优的那个。说谎只能得到$\leq$最优的结果。所以诚实=最优。

\subsubsection{证明2：个体理性(Individual Rationality)}
\textbf{命题：} $\mathbb{E}[V_{\text{settle}}] \geq P_{\text{issue}}$当$\alpha \geq \delta(T) \cdot (1-d_{\text{issue}})$。

\textbf{证明思路：}期望兑付价值的下界是$\alpha \cdot \mathbb{E}[P_{\text{spot}}]$（保底：到期至少可以固定折扣入住）。但实际用户收益通常更高——因为可以在二级市场随时卖出，折扣由市场决定（见连续二级市场冲抵机制）。IR条件在$\alpha=0.70$时已满足；市场驱动路径下条件更宽松。

\subsubsection{证明3：预算平衡(Budget Balance)}
\textbf{命题：} 平台收入≥运营成本。

\textbf{证明思路：} 平台收入=批发-零售价差(8\%加价)+交易手续费(0.3\%)+套现手续费(1.5\%)。运营成本=gas费+预言机成本。费率覆盖比$\kappa\approx2.1>1$。

\textbf{平台刻意设计5倍费率差：} 套现1.5\% vs 交易0.3\%→引导用户选择"卖出冲抵住宿"而非"套现走人"→钱留在生态内。

\subsubsection{连续二级市场冲抵机制（2026年5月新增核心创新）}

\textbf{这是传统三元兑付之上的增强——也是用户成为独立利益方的关键。}

传统三元兑付（保底）：\textbf{只能在到期时}选择。优惠是酒店给的固定折扣$\alpha$——这是时权的价值地板，保证它不会一文不值。

连续二级市场冲抵（主力）：\textbf{随时可以}在二级市场挂单卖出时权。折扣是\textbf{市场供需动态决定的}——需求旺时折扣大，需求弱时折扣小。酒店不承担任何折扣成本。

\textbf{为什么这是革命性的？}
\begin{enumerate}[nosep]
    \item \textbf{优惠是市场给的，不是酒店给的。} 时权二级市场价由供需决定——需求旺时用户折扣更大。酒店一毛钱不出，照样收全额房费。
    \item \textbf{投资和消费解耦。} 用户不必住发行时权的那家酒店——卖时权得的钱可以订任何酒店。
    \item \textbf{平台用费率引导行为。} 交易费0.3\% << 套现费1.5\%——5倍差距，刻意让"卖出冲抵住宿"比"套现"更划算。
    \item \textbf{OTA被绕过了。} OTA抽酒店15-25\%佣金。时权系统：酒店付0\%，平台赚0.3\%交易费，用户省4.4\%——三方改善。
\end{enumerate}

% -------- SECTION 6: EMPIRICAL --------
\subsection{Section 6: Empirical Calibration（实证校准）}

\subsubsection{6.1 Data（数据）}
16,257家酒店来自86,159家成都酒店信息库。1,707,918条日价格记录(2024.3-6)。注意：价格数据单位是\textbf{分}(1CNY=100分)。

\subsubsection{6.8 Over-Issuance Safety（超发安全性）}

$\omega = (1/0.62) \times 0.80 = 1.29\times$。需要77.5\%入住率才能兑付全部时权，预期只有62\%→15.5pp结构性缺口。这个缺口由三元兑付的多样化(不是所有人都选实物入住)和36个月时间窗口分散来弥补。但极端事件(疫情/地震)可能导致兑付失败→信心崩溃→"挤兑"。类比部分准备金银行。

\textbf{safety\_factor(现=0.80)应作为监管参数，而非固定常数。}

\subsubsection*{两层定价结构}

    \item \textbf{用户是第二大受益方(18\%)。} 在旧版模型中用户根本不存在——这是连续二级市场冲抵机制带来的全新利益方。
    \item \textbf{酒店每可用间夜比OTA多赚55\%。} TR模式¥1,602/间夜(确定) vs OTA模式¥1,032/间夜(期望,依赖62\%入住率)。这是系统对酒店的核心卖点。
    \item \textbf{平台只占8\%——但它是最关键的。} 没有平台做市，时权无法流动。平台通过价差+交易费赚钱，同时用5倍费率差引导用户选择"卖出冲抵住宿"而非"套现"。
\end{enumerate}

\subsubsection*{用户如何省钱（具体数字）：}
\begin{itemize}[nosep]

    \item 二级市场卖出：得¥1,264(扣除0.3\%交易费)
    \item 订酒店：房价¥2,029 - 卖出所得¥1,264 = 自付¥765
    \item 总成本：¥1,268 + ¥765 = ¥2,033 ← 和直接订差不多？不！
    \item \textbf{实际总成本：¥1,939}（时权¥1,174批发价+自付¥765）← 因为用户可以通过平台以接近批发价买到时权
    \item \textbf{省了：¥2,029 - ¥1,939 = ¥90 (4.4\%折扣)}
    \item \textbf{关键：这个折扣是市场给的，酒店一毛钱没出。} OTA模式酒店被抽15-25\%佣金。
\end{itemize}

\section{FAQ}

\begin{enumerate}
    \item \textbf{Q: 为什么EL≈0\%？} A: 三元兑付吸收违约冲击 + PD护栏(50\%上限)压缩风险。去掉护栏PD=98\%，去掉兑付EL=1.2\%。
    \item \textbf{Q: NPV +102\%去哪了？} A: 三个bug被修正——现在-42\%。时权不是收入放大器，是风险转移工具。
    \item \textbf{Q: 时权对酒店有价值吗？} A: 有——且价值可量化。每可用间夜¥1,602(确定) vs OTA ¥1,032(期望,依赖62\%入住率)→+55\%。对经济型/舒适型、高OTA依赖、融资困难的酒店最强。对豪华型品牌直销较弱。用户通过市场驱动折扣省钱(4.4\%)——酒店不承担折扣成本。
    \item \textbf{Q: 超发安全吗？} A: $\omega=1.29\times$有15.5pp结构性缺口。正常情况OK(三元兑付分散+时间窗口平滑)，极端事件有挤兑风险。需要监管。
    \item \textbf{Q: 谁最受益？} A: 每份时权创造¥1,227系统价值。酒店66.6\%(+¥817/TR) > 用户18.0\%(+¥221/TR) > 平台8.0\%(+¥98/TR) > 投资者7.4\%(+¥91/TR)。四方都赢——正和机制。酒店每可用间夜比OTA多赚55\%。
    \item \textbf{Q: 200+硬编码参数？} A: 已审计。最重要的参数已可配置(model\_params.py + credit\_model.py构造器)。但"可配置"≠"已校准"——需要外部数据。
\end{enumerate}
